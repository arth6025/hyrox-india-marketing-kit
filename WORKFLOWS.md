Copy a template, fill in the `[brackets]`, send it to Claude. Start with **"HYROX"** so Claude uses the HYROX templates.

### 1. Static post
```
HYROX post (Local cover).
Label: [HYROX INDIA]
Headline: [RACE WITH YOUR FRIENDS]
Subline: [HYROX RELAYS >>]
Photo: attached
```

### 2. Carousel
```
HYROX carousel, [4] slides, from this copy:
[paste copy]
Cover: [8 STATIONS. 8 KM. ONE RACE.]
Finisher: [YOUR RACE STARTS HERE] with button [REGISTER NOW]
Photos: attached
```

### 3. Story set
```
HYROX story set for [race day in Mumbai]:
1. Cover: [OH MY HEADLINE HERE] with this photo
2. Inside: [Race-day timings / The 8 stations / Spectator guide / After-party]
3. CTA: [TELL US YOUR STORY!]
```

### 4. Race / city announcement
```
HYROX event post: [IndusInd Bank] presents HYROX [GUJARAT].
Dates line: [NOVEMBER 26-28 | SEE YOU THERE.]
Then a photo-text slide: [WHAT'S NEW THIS SEASON], date [26.11.26], city [Ahmedabad].
```

### 5. Partner announcement
```
HYROX partner post: [Myprotein], [Global Partner]. Pill: [GLOBAL PARTNERSHIP].
Their logo and a photo are attached.
```

### 6. Athlete or partner quote
```
HYROX quote post (short): partner [Myprotein], name [FOUNDER'S NAME],
quote ["A PARTNERSHIP THAT WORKS"]. Photo attached.
```
Elite 15 athletes have their own HQ templates. Use this one for everyone else.

### 7. Results / stats
```
HYROX stats post: headline [LAST SEASON IN INDIA],
[PARTICIPANTS 6,512] and [CITIES 03]. Full-bleed photo attached.
```

### 8. Race-day schedule
```
HYROX schedule post: headline [RACE DAY],
[26.11.26 07:00 Doors open], [26.11.26 08:00 First heat], [26.11.26 18:00 Awards].
```

### 9. Copy first, then design
```
Write 10 hook options for [HYROX Mumbai registrations opening], HYROX voice: authentic, open to every body.
```
Then: *"Make #[3] a HYROX cover and a story."*

### 10. Image to video / Reel
Make the post first, then:
```
Animate this HYROX post into a [5]-second loop for Instagram.
Keep the text and logo exactly as they are; only the photo moves.
```
Or a Reel from race footage: *"Make a [9]-second Reel from this clip with captions, HYROX style."*
Claude shows the credit cost first and only runs when you say yes.

### 11. No photo? Generate one
```
Using Higgsfield, generate a photo of [an athlete pushing a sled in a dark race hall, editorial, cinematic],
3:4. Then use it in a HYROX cover: [BE AMONG THE BESTS.]
```
Prefer real race photos for Local posts. Generated images suit World-style or concept posts only.

### 12. Check before posting
```
Is this post on-brand for HYROX? Check logo, colours, type and the template rules.
```

---

## Changing a post

Say it plainly: *"use the centred cover"*, *"shorter headline"*, *"more dimming on the photo"*, *"swap the photo"*, *"make a story version"*.
If something needs a layout that doesn't exist, Claude will say so: request it from HQ on Monday.
